# Правила работы с AI

## Инструкция для ассистента

1. Работай с промптами из `ai_prompts/`. Не правь их без необходимости.
2. Параметры заданы в `src/config.json`. Не правь этот файл.
3. Код — в `src/`: `main.py` (симуляция), `aspiration.py` (функции стремления), `growth_func.py` (экспериментальная функция роста, не подключена к `main.py`).
4. Все docstring на русском языке.

Что необходимо уточнить или добавить в промпт? Спроси меня!
— улучши промпт так, как думаешь его надо писать
— сохрани новый промпт в `ai_prompts/`

## Принятые решения

| Вопрос | Решение |
|--------|---------|
| Формула длины/толщины | `b·ln(age) + a` (math.log) |
| Цвет | Линейная интерполяция RGB 0→255, alpha [0,255] |
| Прозрачность | Отдельная линейная интерполяция, SRCALPHA-поверхность |
| Азимут потомка | `angle_родителя + deviation + twist`, затем стремление — наследование через parent_azimuth |
| Отклонение | `±|gauss(азимут_среднее[n], азимут_отклонение[n])|` |
| Скручивание | `twist_родителя + gauss(скручивание_среднее[n], скручивание_отклонение[n])` |
| Стремление | `step_relative(angle, стремление[n], сила_стремления[n])` из `src/aspiration.py`, сила в [0,1] |
| Наследование стремления | Для `n == 0` цель и сила берутся от родителя, иначе из конфига (знак цели случайный) |
| Параметры ДНК | Списки по числу потомков `n`; при выходе за длину — последний элемент |
| Толщина линии | `max(1, int(thickness * 6))` |
| Новые ветки | Не участвуют в розыгрыше той же эпохи |
| Корень | age=0, floor=0, azimuth=0, parent_azimuth=0, start_pos=(0,0) |
| CLI | argparse, -c/--config (по умолчанию `src/config.json`), positional epochs |
| Ошибки | FileNotFoundError/JSONDecodeError → exit(1) |
| Визуализация | pygame, размер из конфига (по умолчанию 1000×800), RESIZABLE, автоподстройка вьюпорта |
| Земля | Прямоугольник снизу, высота = `высота_земли` · высота окна |
| Управление | Пробел — пауза, F10 — развернуть окно, F11 — полный экран, ESC — выход |

## Итерации

- **v1:** matplotlib → pygame. Замена стека визуализации, numpy удалён.
- **v2:** динамический start_pos. parent-ссылка, координаты пересчитываются каждую эпоху.
- **v3:** динамический вьюпорт. Автоматический bounds/scale/offset.
- **v4:** позиционный аргумент epochs. `python3 src/main.py 50`.
- **v5:** скручивание (twist) и стремление угла к цели, параметры ДНК — списки по `n`.
- **v6:** стремление вынесено в модуль `src/aspiration.py` (`step_relative`, `step_absolute`, `closed_form`, `Aspiration`), используется в `main.py`.
- **v7:** документация (README.md, PRD.md, AI_WORKFLOW.md) приведена в соответствие с кодом.

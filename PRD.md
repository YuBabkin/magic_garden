# PRD: Моделирование роста волшебного дерева

## 1. Краткое описание
Десктопное Python-приложение для симуляции и визуализации роста дерева в дискретном времени (эпохи). Дерево растёт, ветвится, меняет цвет и прозрачность с возрастом. Результат — покадровая анимация в окне pygame.

## 2. Целевая аудитория
- Разработчик (создаёт/дорабатывает симуляцию)
- Пользователь, интересующийся процедурной генерацией и визуализацией природных форм

## 3. Функциональные требования

### 3.1. Симуляция роста
| # | Требование | Приоритет |
|---|------------|-----------|
| F1 | Дерево растёт дискретными шагами (эпохами) | MUST |
| F2 | Каждую эпоху возраст всех веток увеличивается на 1 | MUST |
| F3 | Каждая ветка может породить одну новую ветку-потомок за эпоху с заданной вероятностью | MUST |
| F4 | Вновь созданные ветки не участвуют в розыгрыше той же эпохи | MUST |
| F5 | Симуляция начинается с одной корневой ветки в точке (0,0) | MUST |
| F6 | Рост ветки описывается формулой: `length = b * ln(age) + a` | MUST |
| F7 | Толщина ветки описывается формулой: `thickness = b * ln(age) + a` | MUST |

### 3.2. Визуализация
| # | Требование | Приоритет |
|---|------------|-----------|
| V1 | Окно pygame с анимацией роста, 1000×800 | MUST |
| V2 | Цвет ветки — линейная интерполяция RGB от зелёного (молодые) к коричневому (старые) | MUST |
| V3 | Прозрачность (alpha) — линейная интерполяция с возрастом, через SRCALPHA-поверхность | MUST |
| V4 | Толщина линии пропорциональна толщине ветки (scale ×6, минимум 1 px) | MUST |
| V5 | Трава в нижней части окна, линия земли | MUST |
| V6 | Заголовок с номером текущей эпохи | MUST |
| V7 | После завершения всех эпох окно остаётся открытым до закрытия | MUST |

### 3.3. Конфигурация
| # | Требование | Приоритет |
|---|------------|-----------|
| C1 | Все параметры роста загружаются из JSON-файла | MUST |
| C2 | CLI-аргумент `-c/--config` для указания пути к конфигу | MUST |
| C3 | Значения по умолчанию при отсутствии ключей в JSON | MUST |
| C4 | Обработка ошибок: файл не найден → exit(1), невалидный JSON → exit(1) | MUST |

### 3.4. Ветвление
| # | Требование | Приоритет |
|---|------------|-----------|
| B1 | Вероятность spawn потомка зависит от количества已有 потомков (список вероятностей в конфиге) | MUST |
| B2 | Направление новой ветки: `parent_angle + random.gauss(loc, scale)` | MUST |
| B3 | Азимут не накапливается — наследование угла через `parent_angle` | MUST |

### 3.5. Управление
| # | Требование | Приоритет |
|---|------------|-----------|
| U1 | Пробел — пауза/продолжить анимацию | SHOULD |
| U2 | ESC — выход из программы | SHOULD |

## 4. Нефункциональные требования

| # | Требование | Приоритет |
|---|------------|-----------|
| N1 | Единый файл `main.py` | MUST |
| N2 | ООП: классы `DNA`, `Branch`, `Tree` | MUST |
| N3 | Библиотеки: argparse, json, math, random, pygame | MUST |

## 5. Архитектура

### 5.1. Компоненты
```
main.py
├── DNA         — контейнер параметров из config.json
│   └── from_json(path) → DNA
├── Branch      — ветка дерева
│   ├── age, floor, azimuth, start_pos, parent_angle, children
│   ├── angle (property)
│   ├── length(dna), thickness(dna)
│   ├── alpha(dna), color(dna)
│   ├── end_pos(dna)
│   └── spawn_child(dna) → Branch
├── Tree        — дерево (логика роста и отрисовки)
│   ├── root, all_branches, epoch, dna
│   ├── grow()
│   ├── draw(surface, offset_x, offset_y, scale)
│   └── animate()
└── main()      — CLI entry point
```

### 5.2. Конфигурация (config.json)
```json
{
    "физические параметры роста дерева": {
        "длина": {"a": 2.0, "b": 1.5},
        "толщина": {"a": 0.1, "b": 0.15}
    },
    "внешний вид": {
        "цвет_начальный": [34, 139, 34],
        "цвет_конечный": [139, 69, 19],
        "макс_возраст_цвета": 50,
        "alpha_start": 0.2,
        "alpha_end": 1.0,
        "макс_возраст_alpha": 10
    },
    "параметры начала роста новой ветки": {
        "вероятности": [0.5, 0.01, 0.01, 0.2, 0.05],
        "азимут_loc": 0,
        "азимут_scale": 15
    }
}
```

## 6. User Stories

1. **Запуск симуляции** — пользователь запускает `python3 main.py` и видит анимацию роста дерева в окне pygame.
2. **Кастомизация параметров** — пользователь правит `config.json` и получает дерево с другими пропорциями, цветом, ветвлением.
3. **Кастомный конфиг** — пользователь запускает `python3 main.py -c my_tree.json`.
4. **Обработка ошибок** — при ошибочном пути или битом JSON пользователь видит понятное сообщение.
5. **Пауза и выход** — пользователь ставит симуляцию на паузу (пробел) или выходит (ESC).

## 7. Критерии приёмки (Acceptance Criteria)

- [ ] `python3 main.py` запускает анимацию без ошибок
- [ ] `python3 main.py -c nonexistent.json` → сообщение об ошибке, exit(1)
- [ ] `python3 main.py -c broken.json` → сообщение об ошибке, exit(1)
- [ ] Дерево растёт, ветки случайно отклоняются
- [ ] Цвет меняется от зелёного к коричневому
- [ ] Прозрачность растёт с возрастом
- [ ] Ствол толще веток
- [ ] Пробел — пауза/продолжить, ESC — выход
- [ ] Каждый запуск уникален
- [ ] Нет ошибок в консоли при正常 работе

# Волшебное дерево

Симуляция роста дерева на Python с покадровой анимацией. Дерево растёт дискретными эпохами: ветки стареют, удлиняются, толстеют, меняют цвет и случайно ветвятся.

**Стек:** Python, pygame, argparse, JSON.

## Запуск

```bash
python3 src/main.py              # 40 эпох (из config.json)
python3 src/main.py 80           # 80 эпох
python3 src/main.py -c my.json   # свой конфиг
```

**Управление:** Пробел — пауза, F10 — развернуть окно, F11 — полный экран, ESC — выход.

## Как это работает

- **DNA** — контейнер параметров из JSON (коэффициенты длины/толщины, цвета, вероятности ветвления, скручивание, стремление, визуализация)
- **Branch** — ветка: возраст, угол, координаты (через ссылку на родителя), расчёт длины/цвета/прозрачности
- **Tree** — дерево: рост по эпохам, отрисовка через pygame, автоподстройка вьюпорта
- **aspiration** — механизм стремления: значение угла подтягивается к целевому с заданной силой (`step_relative`), есть и альтернативные режимы (`step_absolute`, `closed_form`, класс `Aspiration`)

### Угол новой ветки

```
deviation = ±|gauss(азимут_среднее[n], азимут_отклонение[n])|
twist     = twist_родителя + gauss(скручивание_среднее[n], скручивание_отклонение[n])
angle     = angle_родителя + deviation + twist
angle     = step_relative(angle, стремление[n], сила_стремления[n])
```

`n` — количество уже имеющихся потомков у ветки. Угол ветки: `parent_azimuth + azimuth + twist`.

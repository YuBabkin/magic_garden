# Волшебное дерево

Симуляция роста дерева на Python с покадровой анимацией. Дерево растёт дискретными эпохами: ветки стареют, удлиняются, толстеют, меняют цвет и случайно ветвятся.

**Стек:** Python, pygame, argparse, JSON.

## Запуск

```bash
python3 src/main.py              # 40 эпох (из config.json)
python3 src/main.py 80           # 80 эпох
python3 src/main.py -c my.json   # свой конфиг
```

**Управление:** Пробел — пауза, ESC — выход.

## Как это работает

- **DNA** — контейнер параметров из JSON (коэффициенты длины/толщины, цвета, вероятности ветвления)
- **Branch** — ветка: возраст, угол, координаты (через ссылку на родителя), расчёт длины/цвета/прозрачности
- **Tree** — дерево: рост по эпохам, отрисовка через pygame, автоподстройка вьюпорта

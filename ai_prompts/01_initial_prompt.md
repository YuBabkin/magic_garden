# Промпт: Исходная постановка задачи

## Цель

Программа-игра "Моделирование роста волшебного дерева" на Python с ООП и визуализацией через pygame.
Главный файл `src/main.py`, запуск: `python3 src/main.py [эпохи]`.

## Стек

ООП, Python, pygame.

## Игровая механика ("физика" мира)

### Дискретное время (эпохи)
- **Эпоха** — один шаг симуляции.
- За эпоху:
  1. Увеличивается возраст **всех** существующих веток на 1.
  2. Каждая ветка может породить **одну** новую ветку-потомок (вероятностный механизм).
  3. Вновь созданные ветки НЕ участвуют в розыгрыше той же эпохи.

### Начальное состояние
- Дерево начинает рост с одной корневой ветки.
- Корень: возраст=0, этаж=0, start_pos=(0,0), растёт вертикально вверх.

## Структура

- Единый файл `src/main.py`.
- Классы: `DNA`, `Branch`, `Tree`.
- Все методы и классы с русскоязычными docstring.
- CLI через `argparse`: позиционный аргумент `epochs` (опционально), `-c/--config <путь>`.

## Архитектура — три класса

### DNA — контейнер всех параметров

Загружает и хранит настройки из JSON (`config.json`). Секции:
- физические параметры роста дерева (длина, толщина)
- внешний вид (цвет, alpha)
- параметры начала роста новой ветки (вероятности, азимут)

### Branch — одна ветка

**Поля:** age, floor, azimuth, parent_azimuth, parent (ссылка), children.

**Методы и свойства:**
- `start_pos(dna)` → (x,y): если parent=None → (0,0), иначе parent.end_pos(dna)
- `angle` (property) → parent_azimuth + azimuth
- `length(dna)` → b·ln(age)+a, при age<1 → 0.0
- `thickness(dna)` → b·ln(age)+a, при age<1 → 0.0
- `alpha(dna)` → линейная интерполяция alpha_start → alpha_end
- `color(dna)` → RGBA: линейная интерполяция RGB + alpha
- `end_pos(dna)` → start_pos + length * (cos α, sin α)
- `spawn_child(dna)` → новый Branch с random.gauss(0, scale)

### Tree — дерево

**Поля:** root, all_branches, epoch, dna.

**Методы:**
- `grow()` — одна эпоха: epoch++, age++, spawn (с накоплением новых в отдельный список)
- `bounds()` — bounding box всех start_pos и end_pos
- `draw(surface, width, height)` — рекурсивная отрисовка с автоподстройкой вьюпорта, возвращает ground_sy
- `animate()` — главный цикл pygame: grow → draw → flip

### main() — точка входа

- argparse: epochs (опционально), -c/--config
- DNA.from_json → Tree → animate()
- Обработка FileNotFoundError и JSONDecodeError

## Требования к реализации

- **Структура:** единый файл `src/main.py`.
- **Библиотеки:** argparse, json, math, random, pygame (без numpy).
- **Seed НЕ фиксировать** — каждый запуск уникален.
- **Визуализация:** pygame, 1000×800, SRCALPHA для прозрачности.
- **Автоподстройка:** draw() вычисляет bounds и масштабирует дерево под окно.
- **Координаты:** start_pos вычисляется динамически через parent-ссылку.
- **Управление:** Пробел — пауза, ESC — выход.
- **Обработка ошибок:** файл не найден → exit(1), битый JSON → exit(1).
- **Документация:** русскоязычные docstring для всех классов и методов.
- **Никаких временных файлов.**

## Пример использования

```bash
python3 src/main.py
python3 src/main.py 80
python3 src/main.py -c my_config.json
```

## Примечания

- **Координатная система:** математическая (y вверх) → pygame (y вниз): screen_y = ground_y - tree_y.
- **Угол 90°** для корня → ветка растёт вверх.
- **log(age):** при age=1, ln(1)=0 → длина/толщина = a.
- **RGBA:** pygame RGB [0,255], alpha [0,255]. SRCALPHA-поверхность.
- **Толщина линии:** max(1, int(thickness * 6)).

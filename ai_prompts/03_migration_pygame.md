# Промпт: Переезд с matplotlib на pygame

## Задача

Переписать визуализацию дерева с matplotlib на pygame. Расчётная логика (DNA, Branch, Tree.grow) остаётся без изменений.

## Что нужно сделать

1. Заменить `matplotlib.pyplot` на `pygame`.
2. Удалить `numpy` (использовать `math.log` вместо `np.log`).
3. Tree.draw() должен принимать `pygame.Surface` вместо matplotlib Axes.
4. Tree.animate() — главный цикл pygame вместо plt.ion()/plt.show().

## Требования к отрисовке

- Окно 1000×800, заголовок "Волшебное дерево".
- Цвет ветки: RGBA, где alpha из Branch.alpha(). Использовать `pygame.Surface` с флагом `pygame.SRCALPHA` для прозрачности.
- Толщина линии: `max(1, int(thickness * 6))`.
- Ветка рисуется как отрезок от start_pos до end_pos через `pygame.draw.line()`.
- Фон: светло-голубой (230, 245, 255).
- Земля: зелёная трава (100, 180, 80) от линии ground_y до низа окна.
- Линия земли: тёмно-зелёная (80, 140, 60), толщина 3.

## Требования к анимации

- Главный цикл: обработка событий → grow() → draw() → pygame.display.flip().
- Каждую эпоху пауза 200 мс.
- Пробел — пауза/продолжить.
- ESC — выход.
- После всех эпох окно остаётся открытым до закрытия.

## Адаптация координат

- В matplotlib Y растёт вверх, в pygame Y растёт вниз.
- При отрисовке: screen_y = ground_y - tree_y * scale (с автоподстройкой).

## Подводные камни

- `pygame.draw.line` НЕ использует alpha из цвета, если поверхность не создана с `pygame.SRCALPHA`.
- Толщина линии — int, а не float.
- Хранить дерево на отдельной SRCALPHA-поверхности, blit'ить на экран.

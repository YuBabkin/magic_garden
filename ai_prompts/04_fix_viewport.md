# Промпт: Автоподстройка вьюпорта

## Проблема

Дерево не влезает в окно на большом возрасте. Координаты веток выходят за границы 1000×800.

## Решение

Tree.draw() должен динамически вычислять bounding box дерева и масштабировать/смещать изображение, чтобы дерево всегда помещалось в окно.

## Реализация

1. Добавить метод `Tree.bounds()`, который возвращает `(min_x, min_y, max_x, max_y)` по всем start_pos и end_pos всех веток.

2. В `draw()`:
   - Получить bounds
   - Если диапазон слишком мал (< 0.1), установить дефолт: x: [-40, 40], y: [-10, 80]
   - Добавить 15% отступа с каждой стороны
   - Вычислить center_x, center_y
   - scale = min(width / range_x, height / range_y)
   - to_screen(pos): sx = width/2 + (pos[0] - center_x)*scale, sy = height/2 - (pos[1] - center_y)*scale

3. Вернуть ground_sy = to_screen((0, 0))[1] для отрисовки земли.

4. В `animate()` убрать жёстко зашитые OFFSET_X, GROUND_Y, SCALE. Использовать возвращённый ground_sy для земли.

## Подводные камни

- При нулевой эпохе (только корень, длина=0) bounds = [0,0,0,0] — нужны дефолты.
- Координаты: Y вверх в математике → Y вниз в pygame.
- Земля (y=0) должна быть на правильной высоте, чтобы не было разрыва между травой и деревом.

## 2. Игровая механика ("физика" мира)

### Дискретное время (эпохи)
- **Эпоха** — один шаг симуляции.
- За эпоху:
  1. Увеличивается возраст **всех** существующих веток на 1.
  2. Каждая ветка может породить **одну** новую ветку-потомок (вероятностный механизм).
  3. **Важно:** вновь созданные ветки НЕ участвуют в розыгрыше той же эпохи.

### Начальное состояние
- Дерево начинает рост с одной корневой ветки.
- Корень: возраст=0, этаж=0, start_pos=(0,0), растёт вертикально вверх.

### 4.2. Branch — одна ветка



#### Поля (все задаются в `__init__`)

### Поля (задаются в `__init__`)
- `age` (int) — возраст в эпохах, 0 = новая ветка.
- `floor` (int) — этаж (0 = корень, +1 на уровень вложенности).
- `azimuth` (float) — **случайное отклонение** от направления родителя (градусы). Выборка из `random.gauss(loc, scale)`. Не накапливается.
- `start_pos` (tuple) — координаты (x, y) начала ветки.
- `parent_angle` (float) — абсолютный угол направления **родительской** ветки (градусы). Для корня = 90° (вертикально вверх).
- `children` (list) — список дочерних веток (Branch).






#### Свойства и методы

**`angle` (property):** `parent_angle + azimuth` — абсолютный угол направления роста данной ветки (градусы).

**`length(dna)`:**
- Если `age < 1` → 0.0
- Иначе → `dna.length_b * ln(age) + dna.length_a` (натуральный логарифм)

**`thickness(dna)`:**
- Если `age < 1` → 0.0
- Иначе → `dna.thickness_b * ln(age) + dna.thickness_a`

**`alpha(dna)`:**
- `t = min(1.0, age / dna.alpha_max_age)`
- `dna.alpha_start + t * (dna.alpha_end - dna.alpha_start)`

**`color(dna)`:**
- `t = min(1.0, age / dna.color_max_age)`
- `r = color_start[0] + t * (color_end[0] - color_start[0])` (аналогично g, b)
- `return (r/255, g/255, b/255, self.alpha(dna))`

**`end_pos(dna)`:**
- `l = self.length(dna)`
- `α = math.radians(self.angle)`
- `x = self.start_pos[0] + l * cos(α)`
- `y = self.start_pos[1] + l * sin(α)`

**`spawn_child(dna)`:**
- `deviation = random.gauss(dna.azimuth_loc, dna.azimuth_scale)`
- Создаёт `Branch(age=0, floor=self.floor+1, azimuth=deviation, start_pos=self.end_pos(dna), parent_angle=self.angle)`
- **ВАЖНО:** `azimuth` = только deviation. Не прибавляется `self.azimuth`! Наследование направления происходит через `parent_angle = self.angle`.

Функционально зависят от физических параметров

**Координаты** (x, y) начала ветки -- координаты конца родительской ветки. Пересчитываются для каждой эпохи в связи с ростом веток. |

**Длина:** `length = b * log(age) + a`
- При age < 1 → длина = 0 (иначе log(0) не определён).
- Коэффициенты a, b — из ДНК (секция "длина").

**Толщина:** `thickness = b * log(age) + a`
- При age < 1 → толщина = 0.
- Коэффициенты a, b — из ДНК (секция "толщина").

**Цвет:** линейная интерполяция от начального к конечному цвету (RGB 0–255).

**Прозрачность (alpha):** линейная интерполяция.

Задаются в ДНК:
`alpha_start`, `alpha_end`, `макс_возраст_alpha` — из ДНК.

**Итоговый цвет для matplotlib:** RGBA, где компоненты RGB делятся на 255 (диапазон 0–1), alpha — из интерполяции выше.

### Розыгрыш новой ветки (один раз за эпоху для каждой существующей ветки)

1. **Вероятность:** по списку `[p0, p1, p2, ...]`, где p_n — вероятность появления новой ветки, если у родителя уже n потомков. Если число потомков >= длина списка → вероятность = 0.

2. **Создание новой ветки** (при успешном розыгрыше):
   - `age = 0`,
   - `floor = parent.floor + 1`
   - `start_pos = parent.end_pos` (координаты конца родительской ветки)
   - `theta = parent.theta + random.gauss(mu, sigma)` — накапливает отклонение

## Класс Tree (Дерево)

### Поля
- `root = Branch(age=0, floor=0, azimuth=0, start_pos=(0,0), parent_angle=90)`
- `all_branches` — список всех веток (для плоской итерации).
- `epoch` — счётчик эпох (начинается с 0).
- `dna` — экземпляр DNA.

### Методы

### grow() — одна эпоха роста
1. `self.epoch += 1`
2. Для каждого branch в `self.all_branches`: `branch.age += 1`
3. `new_branches = []`
4. Для каждого branch в `self.all_branches`:
   - `n = len(branch.children)`
   - `prob = dna.probabilities[n]` если `n < len(dna.probabilities)`, иначе 0.0
   - Если `random.random() < prob`:
     - `child = branch.spawn_child(dna)`
     - `branch.children.append(child)`
     - `new_branches.append(child)`
5. `self.all_branches.extend(new_branches)`

### draw(ax) — отрисовка дерева
- Рекурсивный обход от корня.
- Каждая ветка — отрезок от `start_pos` до `end_pos`. `start_pos` это `end_pos` ветки-родителя
- Толщина линии: `max(0.5, thickness * 6)`.
- Цвет линии: RGBA из метода `color()`.
- `ax.set_aspect("equal")`, `ax.axis("off")`.
- Заголовок: `f"Волшебное дерево — Эпоха {self.epoch}"`.

### animate() — анимация роста
- Интерактивный режим matplotlib (`plt.ion()`).
- Для каждой эпохи: `grow()` → очистка осей → `draw()` → пауза 200ms.
- После всех эпох — `plt.ioff()`, `plt.show()` (финальный кадр остаётся открытым).

## 8. Примечания для разработчика

- **Координатная система matplotlib:** x — вправо, y — вверх. cos/sin от угла в радианах.
- **Угол 90°** для корня => `x += l*cos(90°)=0`, `y += l*sin(90°)=l` → ветка растёт вверх.
- **log(age):** при age=1, ln(1)=0 → длина/толщина = a (базовое значение).
- **RGBA:** matplotlib ожидает компоненты в [0, 1]. RGB из [0,255] делим на 255.
- **linewidth:** `max(0.5, thickness * 6)` — минимальная толщина линии 0.5 pt.
- **solid_capstyle='round'** для скруглённых концов веток.

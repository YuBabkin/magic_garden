## Цель

Программа-игра "Моделирование роста волшебного дерева" на Python с ООП и визуализацией через matplotlib.
Главный файл `main.py`, запуск: `python3 main.py [-c config.json]`.

## Основные понятия

Дерево состоит из веток. Рост дискретен по времени.

**Эпоха** — один шаг программы. За одну эпоху:
1. Увеличивается возраст каждой ветки → пересчёт длины, толщины, цвета, прозрачности.
2. Происходит розыгрыш появления новых веток-потомков (вероятностный механизм).
   **Важно:** вновь созданные ветки НЕ участвуют в розыгрыше той же эпохи.

Дерево начинает рост с первой корневой ветки.

## Класс Branch (Ветка)

### Физические параметры

| Поле | Описание |
|------|----------|
| `age` | Возраст в эпохах. 0 для новой ветки, +1 за каждую эпоху. |
| `floor` | Номер этажа (0 для корня, +1 для каждого уровня вложенности). |
| `children` | Список дочерних веток. |
| `theta` | **Абсолютный** угол направления роста ветки от нормали к поверхности. Для корня = 0° (вверх). Потомок получает `parent.theta + random_gauss(mu, sigma)`, где mu sigma задаются в ДНК. |


### Визуальные свойства.
Функционально зависят от физических параметров

**Координаты** (x, y) начала ветки -- координаты конца родительской ветки. Пересчитываются для каждой эпохи в связи с ростом веток. |

**Длина:** `length = b * log(age) + a`
- При age < 1 → длина = 0 (иначе log(0) не определён).
- Коэффициенты a, b — из ДНК (секция "длина").

**Толщина:** `thickness = b * log(age) + a`
- При age < 1 → толщина = 0.
- Коэффициенты a, b — из ДНК (секция "толщина").

**Цвет:** линейная интерполяция от начального к конечному цвету (RGB 0–255).

Параметры задаются в ДНК:
epoch = [0, 15, 30]
color = [red, green, broun]

**Прозрачность (alpha):** линейная интерполяция.

t = min(1, age / max_age)
alpha = alpha_start + t * (alpha_end - alpha_start)

Задаются в ДНК:
`alpha_start`, `alpha_end`, `макс_возраст_alpha` — из ДНК.

**Итоговый цвет для matplotlib:** RGBA, где компоненты RGB делятся на 255 (диапазон 0–1), alpha — из интерполяции выше.

### Розыгрыш новой ветки (один раз за эпоху для каждой существующей ветки)

1. **Вероятность:** по списку `[p0, p1, p2, ...]`, где p_n — вероятность появления новой ветки, если у родителя уже n потомков. Если число потомков >= длина списка → вероятность = 0.

2. **Создание новой ветки** (при успешном розыгрыше):
   - `age = 0`,
   - `floor = parent.floor + 1`
   - `start_pos = parent.end_pos` (координаты конца родительской ветки)
   - `theta = parent.theta + random.gauss(mu, sigma)` — накапливает отклонение

## Класс Tree (Дерево)

### Поля
- Корневая ветка: `Branch(age=0, floor=0, azimuth=0, start_pos=(0,0), parent_angle=90)`
- Список всех веток для итерации.
- Счётчик эпох.

### grow() — одна эпоха роста
1. `epoch += 1`
2. `age += 1` для всех существующих веток.
3. Для каждой ветки — розыгрыш новой ветки (созданные потомки НЕ участвуют в розыгрыше текущей эпохи).
4. Созданные ветки добавляются в общий список.

### draw(ax) — отрисовка дерева
- Рекурсивный обход от корня.
- Каждая ветка — отрезок от `start_pos` до `end_pos`.
- Толщина линии: `max(0.5, thickness * 6)`.
- Цвет линии: RGBA из метода `color()`.
- `ax.set_aspect("equal")`, `ax.axis("off")`.
- Заголовок с номером текущей эпохи.

### animate() — анимация роста
- Интерактивный режим matplotlib (`plt.ion()`).
- Для каждой эпохи: `grow()` → очистка осей → `draw()` → пауза 200ms.
- После всех эпох — `plt.ioff()`, `plt.show()` (финальный кадр остаётся открытым).

## Входные данные (config.json — ДНК дерева)

Файл в формате JSON с русскоязычными ключами (пример):

```json
{
    "физические параметры роста дерева": {
        "длина": {"a": 2.0, "b": 1.5},
        "толщина": {"a": 0.3, "b": 0.4}
    },
    "внешний вид": {
        "цвет_начальный": [34, 139, 34],
        "цвет_конечный": [139, 69, 19],
        "макс_возраст_цвета": 50,
        "alpha_start": 0.2,
        "alpha_end": 1.0,
        "макс_возраст_alpha": 20
    },
    "параметры начала роста новой ветки": {
        "вероятности": [0.5, 0.25, 0.15, 0.1, 0.05],
        "азимут_loc": 0,
        "азимут_scale": 25,
        "эпох": 40
    }
}
```

## Требования к реализации
- **Структура:** единый файл `main.py`.
- **CLI:** `argparse`, аргумент `-c`/`--config` (по умолчанию `config.json`).
- **Обработка ошибок:** файл не найден → сообщение + exit(1); некорректный JSON → сообщение об ошибке + exit(1).
- **ООП:** классы `DNA` (загрузка и хранение параметров), `Branch` (ветка), `Tree` (дерево).
- **Визуализация:** `matplotlib`, анимация роста эпоха за эпохой.
- **Документация:** все методы и классы снабдить docstring (русский язык).
- **Чистота:** не использовать `garbage.txt`, временные файлы; настройки только через JSON-конфиг.

## Неоднозначности и уточнения
- **Случайность:** `random.gauss` без фиксации seed — каждый запуск уникален.
- **Рост на первом шаге:** эпоха 1: корень age=1 → длина/толщина > 0, розыгрыш потомков.

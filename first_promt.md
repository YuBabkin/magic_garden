## Цель
Имитация роста дерева

## структура программы

Главная сущность -- это дерево. Дерево состоит из веток. Рост дерева начинается с первой ветки.
Рост дискретен от времени. Эпоха -- один шаг программы роста -- работа функции роста для каждой из существующих векток.

### ветка дерева
Имеет параметры:
* Первичные параметры:
- возраст
- номер этажа
- список веток-потомков
- азимут роста
* Вторичные параметры (вычисляемые):
- толщина
- длина
- цвет

### функция отрастания новой ветки
Функция работает для каждой ветки один раз за эпоху.

1. Рассчитывается вероятность отрастания новой ветки. Вероятность задаётся в конфиге (ДНК дерева)

2. Если отрастает новая ветка -- рассчитываются параметры новой ветки.

### функция рассчёта вторичных параметров дерева
Толщина и длина -- функции, обеспечивающие плавный рост, который с эпохами замедляется. Параметры скорости роста задаются в конфиге

Цвет -- задаётся функцией, агрументами которой является возраст ветки, первый цвет, второй цвет. Цвет ветки -- есть градиент от первого цвета до второго. Оба цвета задаются в конфиге.

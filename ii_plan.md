## Понимание задачи (после анализа)

Программа-игра "Моделирование роста волшебного дерева" на Python с ООП и визуализацией matplotlib.

### Как я понял задачу

**Суть:** Дерево растёт дискретными шагами (эпохами). Каждую эпоху все ветки стареют, удлиняются, толстеют, меняют цвет, и каждая может породить новую ветку-потомок с заданной вероятностью. Результат визуализируется покадровой анимацией.

**Ключевые решения и допущения:**

| Вопрос | Решение |
|--------|---------|
| Формула длины/толщины | `b·ln(age) + a` (log — натуральный, `numpy.log`) |
| Цвет | Линейная интерполяция RGB 0→255 с age, затем /255 для matplotlib |
| Прозрачность | Отдельная линейная интерполяция alpha, входит в RGBA |
| Азимут потомка | `parent.azimuth + gauss(loc, scale)` — накопление отклонения |
| Толщина линии | `max(0.5, thickness * 6)` |
| Новые ветки | Не участвуют в розыгрыше той же эпохи (собираются в отдельный список) |
| Корень | `age=0, floor=0, azimuth=0, start_pos=(0,0), parent_angle=90` |
| CLI | `argparse`, `-c/--config`, умолчание `config.json` |
| Ошибки | FileNotFoundError/JSONDecodeError → сообщение + `exit(1)` |
| Файловая структура | Один файл `main.py` |
| Язык кода | Русские docstring, русскоязычные ключи в JSON |

### План реализации

```
1. DNA (статический контейнер)
   └─ from_json(path) → загрузить JSON, распарсить секции

2. Branch (ветка)
   ├─ Первичные поля: age, floor, azimuth, start_pos, parent_angle, children
   ├─ Свойства: angle, length(), thickness(), color(), alpha(), end_pos()
   └─ spawn_child() → создать потомка со случайным азимутом

3. Tree (дерево)
   ├─ root: корневая ветка
   ├─ all_branches: плоский список для итерации
   ├─ grow(): epoch++ → age++ → spawn (однократно)
   ├─ draw(): рекурсивная отрисовка отрезков
   └─ animate(): plt.ion() → цикл эпох → plt.ioff()

4. main()
   ├─ argparse
   ├─ DNA.from_json()
   ├─ Tree(dna).animate()
   └─ обработка исключений
```

### Порядок разработки
1. Скелет классов DNA, Branch, Tree
2. Реализация DNA — загрузка и хранение параметров
3. Реализация Branch — все расчётные методы
4. Реализация Tree — grow, draw
5. Анимация и CLI
6. Обработка ошибок
7. Docstring и финальная проверка

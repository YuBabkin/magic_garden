## Цель
Программа-игра "Моделирование роста волшебного дерева". Имитация роста дерева.

## Контекст проекта
Написать программу на Python. Использовать ООП. Визуализация через matplotlib.

## Структура программы

Главная сущность -- это дерево. Дерево состоит из веток. Рост дерева начинается с первой ветки.
Рост дискретен от времени. Эпоха -- один шаг программы роста -- работа функции роста для каждой из существующих веток.

### Ветка дерева
Имеет параметры:
* Первичные параметры:
  - возраст (номер эпохи, в которую ветка появилась)
  - номер этажа (0 для корня, +1 для каждого уровня)
  - список веток-потомков
  - азимут роста (угол в градусах относительно направления родителя)
* Вторичные параметры (вычисляемые):
  - толщина
  - длина
  - цвет

### Функция отрастания новой ветки
Функция работает для каждой ветки один раз за эпоху.

1. Рассчитывается вероятность отрастания новой ветки. Вероятность задаётся в конфиге (ДНК дерева). В зависимости от количества уже отросших веток -- задаётся своя вероятность. Формула: `probability = base * decay^count`, где `base` -- базовая вероятность, `decay` -- коэффициент затухания (0..1), `count` -- количество уже имеющихся потомков.

2. Если отрастает новая ветка -- рассчитываются параметры новой ветки. Азимут -- как у ветки предка, плюс случайная величина из диапазона [azimuth_min, azimuth_max].

### Функция расчёта вторичных параметров ветки
Толщина и длина -- функции, обеспечивающие плавный рост, который с эпохами замедляется: `a * (1 - exp(-b * age))`, где `a` и `b` -- параметры роста из конфига.

Цвет -- задаётся функцией, аргументами которой является возраст ветки, первый цвет, второй цвет. Цвет ветки -- градиент от первого цвета до второго. Линейная интерполяция: `color = color_start + t * (color_end - color_start)`, где `t = min(1, age / max_age)`. Оба цвета задаются в конфиге.

### Отрисовка всего дерева
После завершения симуляции строится изображение. Каждая ветка -- отрезок от `start_pos` до `end_pos`. Толщина линии пропорциональна толщине ветки. Цвет линии -- цвет ветки. Корневая ветка начинается в точке (0, 0) и растёт вертикально вверх (угол 90°). Дочерние ветки рисуются рекурсивно относительно родительских. Формат: matplotlib, равный масштаб по осям, оси скрыты, заголовок с номером эпохи.

## Входные данные
ДНК дерева задаётся в JSON-конфиге с тремя секциями:

Секция "физические параметры роста дерева":
- длина: { a, b }
- толщина: { a, b }

Секция "внешний вид":
- цвет_начальный: [R, G, B]
- цвет_конечный: [R, G, B]

Секция параметров начала роста новой ветки:
- вероятность_базовая (float, 0..1) -- вероятность появления первой ветки-потомка
- вероятность_затухание (float, 0..1) -- множитель вероятности на каждого следующего потомка
- максимум_потомков (int) -- максимальное число потомков у одной ветки
- азимут_мин (float, градусы) -- минимальное отклонение азимута
- азимут_макс (float, градусы) -- максимальное отклонение азимута
- эпох (int) -- количество эпох симуляции

## Требования к выходу
- Формат: окно matplotlib с изображением дерева
- Принимать путь к конфигу как аргумент командной строки (по умолчанию config.json)
- Обработка ошибок: проверка существования файла, валидность JSON, наличие обязательных секций

## Пример использования
```
$ python main.py config.json
# Открывается окно matplotlib с нарисованным деревом
```

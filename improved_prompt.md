## Понимание задачи

Программа-игра "Моделирование роста волшебного дерева" на Python с ООП и визуализацией через matplotlib.

### Сущности

**Branch (Ветка):**
- Хранит: age, floor, children, azimuth, parent_angle, start_pos
- Вычисляет: angle = parent_angle + azimuth
- Вычисляет длину/thickness по формуле b*log(age)+a (при age<1 → 0)
- Вычисляет цвет/прозрачность линейной интерполяцией от начальных к конечным значениям
- Каждую эпоху пытается породить новую ветку с вероятностью из списка [p0, p1, ...] по числу потомков
- azb = random.gauss(loc, scale) при каждом рождении

**Tree (Дерево):**
- Корень: Branch(age=0, floor=0, azimuth=0, start_pos=(0,0), parent_angle=90)
- grow(): epoch++ → age всех веток++ → розыгрыш новых веток
- draw(): рекурсивно рисует отрезки от start_pos до end_pos

**Входные данные:** config.json (ДНК дерева) с русскими ключами

### План реализации

1. Парсинг config.json через argparse
2. Класс Branch с полями и вычисляемыми свойствами
3. Класс Tree с grow() и draw()
4. Анимация matplotlib: показываем дерево после каждой эпохи
5. Обработка ошибок: файл не найден, некорректный JSON

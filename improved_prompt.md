## Цель
Программа-игра "Моделирование роста волшебного дерева" на Python с ООП и визуализацией через matplotlib.

## Структура программы
Моделирование роста дерева. Дерево состоит из веток. Рост дискретен по времени.
**Эпоха** — один шаг программы. За одну эпоху:
1. Рассчитывается рост каждой из веток (инкремент возраста → пересчёт длины, толщины, цвета)
2. Происходит розыгрыш отрастания новых веток (вероятностный)

## Ветка дерева (Branch)

### Первичные параметры (задаются при создании)
- `age` — возраст в эпохах (0 для новой ветки, инкремент +1 за эпоху)
- `floor` — номер этажа (0 для корня, +1 для каждого уровня)
- `children` — список веток-потомков
- `azimuth` — угол (в градусах) отклонения от направления родительской ветки
- `parent_angle` — абсолютный угол направления родительской ветки
- `start_pos` — координаты (x, y) начала ветки (конец родительской ветки)
- Вычисляемое свойство: `angle = parent_angle + azimuth` (абсолютный угол роста)

### Вторичные параметры (вычисляются от возраста)

**Длина:** `length = b * log(age) + a`
- Для age < 1 (новая, ещё не росла) → длина = 0
- Коэффициенты a, b задаются в ДНК (секция "длина")

**Толщина:** `thickness = b * log(age) + a`
- Для age < 1 → толщина = 0
- Коэффициенты a, b задаются в ДНК (секция "толщина")

**Цвет:** градиент от начального к конечному цвету
- `t = min(1, age / max_age)`
- `color = color_start + t * (color_end - color_start)` (линейная интерполяция)
- Цвета (RGB 0–255) и max_age задаются в ДНК

**Прозрачность (alpha) при отрисовке:**
- `t = min(1, age / max_age)` (свой max_age для alpha, независимый от цвета)
- `alpha = alpha_start + t * (alpha_end - alpha_start)` (линейная интерполяция)
- alpha_start, alpha_end, max_age задаются в ДНК
- Итоговый цвет для matplotlib: (r, g, b, alpha) в диапазоне 0–1

### Розыгрыш новой ветки (один раз за эпоху для каждой ветки)

1. **Вероятность:** по списку `[p0, p1, p2, ...]`, где p_n — вероятность появления новой ветки, если у родителя уже n потомков. Если число потомков превышает длину списка → вероятность = 0.
2. **Создание новой ветки:**
   - `age = 0`, `floor = parent.floor + 1`
   - `azimuth = parent.azimuth + azb`
   - `azb = random.gauss(loc, scale)` — нормальное распределение, пересчитывается при каждом создании
   - loc, scale задаются в ДНК
   - `parent_angle = parent.angle`
   - start_pos вычисляется после розыгрыша (через end_pos родителя, уже с новым возрастом)

### Координаты конца ветки
- `end_pos = (x + length * cos(radians(angle)), y + length * sin(radians(angle)))`

## Дерево (Tree)

- Содержит корневую ветку (`Branch(age=0, floor=0, azimuth=0, start_pos=(0,0), parent_angle=90)`)
- Список всех веток для итерации

### grow()
1. `epoch += 1`
2. `age += 1` для всех существующих веток
3. Для каждой ветки — розыгрыш новой ветки
4. Созданные ветки добавляются в общий список

### draw()
- Рекурсивный обход от корня
- Каждая ветка — отрезок от start_pos до end_pos
- Толщина линии: `max(0.5, thickness * scale_factor)` (scale_factor ~6)
- Цвет линии из color() с учётом alpha (RGBA)
- `ax.set_aspect("equal")`, `ax.axis("off")`, заголовок с номером эпохи

## Входные данные (config.json, ДНК дерева)

```json
{
  "физические параметры роста дерева": {
    "длина": { "a": 2.0, "b": 1.0 },
    "толщина": { "a": 0.3, "b": 0.2 }
  },
  "внешний вид": {
    "цвет_начальный": [34, 139, 34],
    "цвет_конечный": [139, 69, 19],
    "макс_возраст_цвета": 30,
    "alpha_start": 0.2,
    "alpha_end": 1.0,
    "макс_возраст_alpha": 20
  },
  "параметры начала роста новой ветки": {
    "вероятности": [0.5, 0.01, 0.5, 0.01, 0.5],
    "азимут_loc": 0,
    "азимут_scale": 5,
    "эпох": 40
  }
}
```

## Требования к реализации
- Обработка ошибок: файл не найден, некорректный JSON
- argparse/argv: путь к конфигу как аргумент, по умолчанию config.json
- age < 1 → длина/толщина = 0 (log(0) не определён)

## Пример использования
```
$ python main.py config.json
# Открывается окно matplotlib с нарисованным деревом
```
